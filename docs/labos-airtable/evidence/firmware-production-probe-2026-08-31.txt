READ-ONLY GUARANTEE
-------------------
Every command below is read-only. Nothing was started, stopped, restarted,
rebuilt, deployed, written or deleted. No rig motion, no VFD command, no valve
command, no test created, no MQTT publish, no DB write, no migration, no
docker cp into a container, no git operation that touches a worktree.

Three classes of command were used and nothing else:
  * inspection      — docker ps / images / inspect / logs, git rev-parse, md5sum
  * file reads      — cat, sed -n, grep, find, python3 -c json.load(...)
  * SELECT-only SQL — psql -f with a file containing only SELECT and \echo

Two writes to *scratch* paths outside any container's app tree were made purely
to carry SELECT-only SQL to the database host:
    ssh-copy.sh push management probeN.sql /tmp/probeN.sql
    docker cp /tmp/probeN.sql ifet-management-db-1:/tmp/probeN.sql
These touch /tmp only. They are not hot patches: no file under /app, no config,
no bind-mounted path and no image layer was modified.

Deliberately NOT done (would have changed state — see report §17):
  * publishing device{N}/command to start a test
  * publishing sick/assign or sick/release to exercise a deflection gauge
  * POST/PUT to report-api (would create a trial or flip finished/resume)
  * writing UNIT_OF_MEASUREMENT or restarting a gateway to test unit handling

Statements used (all SELECT):

  SELECT * FROM alembic_version;                       -- 3a65a83e0463

  SELECT COALESCE(result::text,'NULL'), count(*) FROM test_results GROUP BY 1;
  SELECT (SELECT count(*) FROM test_results), (SELECT count(*) FROM deflections),
         (SELECT count(*) FROM projects);

  SELECT count(*), min(max_deflection), max(max_deflection),
         min(permanent_deflection), max(permanent_deflection),
         min(recovery), max(recovery) FROM deflections;

  SELECT deflection_gauge, count(*) FROM deflections GROUP BY 1 ORDER BY 1;

  -- provenance split: the single most load-bearing query in the report
  SELECT CASE WHEN deflection_gauge LIKE 'Gauge%' THEN 'GaugeN' ELSE 'SICK' END scheme,
         count(*), count(DISTINCT recovery), min(test_id), max(test_id),
         round(min(max_deflection)::numeric,2), round(max(max_deflection)::numeric,2)
  FROM deflections GROUP BY 1;

  SELECT CASE WHEN EXISTS(SELECT 1 FROM deflections d WHERE d.test_id=tr.id
                            AND d.deflection_gauge LIKE 'Gauge%') THEN 'has GaugeN'
              WHEN EXISTS(SELECT 1 FROM deflections d WHERE d.test_id=tr.id) THEN 'has SICK'
              ELSE 'no deflections' END,
         COALESCE(tr.result::text,'NULL'), count(*)
  FROM test_results tr GROUP BY 1,2;

  -- raw-count reconstruction (0.0393701 = the gateway's MM_TO_INCH)
  SELECT max_deflection, round((max_deflection/0.0393701)::numeric,3) implied_raw_count,
         abs(round((max_deflection/0.0393701)::numeric)
             - (max_deflection/0.0393701)::numeric) int_residual
  FROM deflections WHERE max_deflection <> 0 ORDER BY abs(max_deflection) DESC LIMIT 12;

  SELECT length(split_part(abs(max_deflection)::text,'.',2)) dp, count(*)
  FROM deflections GROUP BY 1 ORDER BY 1;

  SELECT type, count(*), min(pressure), max(pressure), min(duration), max(duration),
         min(leakage), max(leakage) FROM infiltration_tests GROUP BY 1;
  SELECT duration, count(*) FROM infiltration_tests GROUP BY 1 ORDER BY 2 DESC;

  SELECT duration, count(*) FROM static_tests GROUP BY 1 ORDER BY 2 DESC;
  SELECT COALESCE(NULLIF(pressure_factor,''),'(empty)'), count(*),
         min(duration), max(duration) FROM static_tests GROUP BY 1;
  SELECT preset, count(*), count(DISTINCT project_id) FROM static_tests GROUP BY 1;
  SELECT preset, count(*), count(DISTINCT project_id) FROM cyclic_tests GROUP BY 1;
  SELECT cycles, count(*) FROM cyclic_tests GROUP BY 1 ORDER BY 2 DESC;
  SELECT n_stages, count(*) FROM (SELECT project_id, count(*) n_stages
      FROM static_tests GROUP BY 1) q GROUP BY 1 ORDER BY 1;

  -- the water stage is 0.15 x INWARD design pressure, 900 s, filed as a static test
  SELECT s.project_id, s.index, s.pressure, p.inward_design_pressure,
         round((s.pressure/NULLIF(p.inward_design_pressure,0))::numeric,4) ratio
  FROM static_tests s JOIN projects p ON p.id=s.project_id WHERE s.duration=900;

  SELECT project_id,index,type,pressure,pressure_factor,duration,preset,finished
  FROM static_tests WHERE preset=false ORDER BY project_id;
  SELECT project_id,index,type,cycles,low_pressure,high_pressure,preset,finished,current_cycle
  FROM cyclic_tests WHERE preset=false;

  -- the project behind the 2026-08-26 runtime exhibit
  SELECT id,name,device_id,inward_design_pressure,outward_design_pressure
  FROM projects WHERE id=78;
  SELECT index,type,cycles,low_pressure,high_pressure,finished,resume,current_cycle,preset
  FROM cyclic_tests WHERE project_id=78 ORDER BY index;
  SELECT project_id,index,type,pressure,pressure_factor,duration,preset,finished
  FROM static_tests WHERE project_id=78 ORDER BY index;

  SELECT id,name,turbo_mode,turbo_slave,turbo_charger FROM devices ORDER BY id;
  SELECT (SELECT count(*) FROM missile_impact_tests), (SELECT count(*) FROM shots);
  SELECT COALESCE(result::text,'NULL'), count(*) FROM shots GROUP BY 1;
  SELECT count(*) FROM test_results tr
    WHERE NOT EXISTS (SELECT 1 FROM deflections d WHERE d.test_id=tr.id);
